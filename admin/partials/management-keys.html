Management Keys

Third-party provider management/provisioning keys (e.g. OpenRouter). Always encrypted client-side to selected registered devices — this server never sees the plaintext. Generating and revoking keys on the provider works from both the CLI (kv mgmt-key keys ...) and here, by decrypting the management key with this browser's registered device key and calling the provider directly.
